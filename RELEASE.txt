MacKeys (Windows x64)

Open MacKeysSetup.exe for settings. It does not start mapping when opened.
Open MacKeysRun.exe to start saved mapping in the background.
AutoHotkey and .NET installation are not required.

Use Enable/Disable Mapping in settings to control mapping explicitly.
Save and Apply updates an active mapping and saves settings; it does not
start mapping when mapping is stopped.
Closing settings exits the settings window without stopping mapping.
Right-click the mapping worker's tray icon and choose Stop mapping to stop it.

Click Add to Startup at the bottom of settings to install background startup.
The installer replaces the previous Startup MacKeys.exe entry and does not
start, stop, or switch either application. Startup remains opt-in.

Settings: %APPDATA%\MacKeymap-AHK\config.json
This existing folder name is retained for compatibility.
Version 3 settings from the older app can be imported without overwriting
the original file. Imported settings start with mapping disabled.

The EXE is unsigned. Real application and keyboard behavior still needs
testing. Keep the complete package, including licenses/ and source/.
